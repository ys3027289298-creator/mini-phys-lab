# 推导与取舍细节

## 1. 静止临界角

质心不动，`a = 0`，`α = 0`。沿坡与法向平衡：

```
m g sinθ + f = 0        ⇒  f = −m g sinθ
N − m g cosθ = 0        ⇒  N = m g cosθ
```

约束 `|f| ≤ μN`：

```
m g sinθ ≤ μ m g cosθ   ⇒   tanθ ≤ μ   ⇒   tanθ_s = μ
```

## 2. 无滑滚动临界角

接触点瞬时静止：`u = v + Rω = 0`，求导得 `a = −Rα`。力矩与牛顿第二定律：

```
I α = R f
m a = m g sinθ + f
```

代入 `α = −a/R`：

```
I (−a/R) = R f          ⇒   a = −R² f / I
m (−R² f / I) = m g sinθ + f
⇒ f (1 + mR²/I) = −m g sinθ
⇒ f = −m g sinθ / (1 + mR²/I) = −m g sinθ · β/(1+β)
```

其中 `β = I/(mR²)`。注意 `|f|` 比静止情形小 `β/(1+β)` 倍。约束 `|f| ≤ μN = μ m g cosθ`：

```
m g sinθ · β/(1+β) ≤ μ m g cosθ
⇒ tanθ ≤ μ (1+β)/β   ⇒   tanθ_r = μ(1+β)/β
```

## 3. 大小关系

```
tanθ_r / tanθ_s = (1+β)/β = 1 + m R²/I
```

因 `m R²/I > 0`，恒有 `θ_r > θ_s`。转动惯量越大（β 越大），`(1+β)/β` 越小，两角越接近；`I → ∞`（β→∞）时比值为 1，两临界角重合；`I → 0`（质点，β→0）时比值发散。

| 物体 | β | 比值 |
|---|---|---|
| 实心球 | 2/5 | 3.5 |
| 空心球 | 2/3 | 2.5 |
| 圆环 | 1 | 2.0 |

同一 `μ = 0.3896` 下：实心球 `θ_s=21.3°, θ_r=53.7°`；空心球 `θ_r=44.2°`；圆环 `θ_r=37.9°`。

## 4. 独立验证：接触点滑移加速度

设接触点滑移 `u = v + Rω`。滑动时动摩擦 `f = −μN·sgn(u)`：

```
a   = g sinθ − μ g cosθ · sgn(u)
α   = R f / I = −μ g cosθ · sgn(u) · m R² / I
du/dt = a + Rα
      = g sinθ − μ g cosθ sgn(u) (1 + m R²/I)
      = g cosθ [ tanθ − μ(1+1/β) sgn(u) ]
```

对 `u > 0`，`du/dt < 0` 的条件是 `tanθ < μ(1+1/β) = μ(1+β)/β`，即 `θ < θ_r`。与第 2 节一致。代码 `slip_accel_below_negative` / `slip_accel_above_positive` 检查的就是这条。

## 5. 动摩擦陷阱

速度型摩擦 `f_t = μ|v_normal|` 在 `v_normal = 0` 时恒为零。静止接触若走这条分支，切向力为零，质心自由下滑。因此静摩擦必须：

1. 按力平衡求所需切向力；
2. 与 `μN` 比较，超出则饱和为动摩擦；
3. 不依赖相对速度的大小。

代码里 `simulate_kinetic_only()` 保留错误分支作对照：20° 坡 10 s 位移 119.8 m，而正确分支为 0。

## 6. 系数取舍模型

设真实倾角恰在 20°（最坏情形），测量/设定角度带噪声 `θ_meas ~ N(20°, σ²)`，`σ = 0.5°`。系数放大 `m` 倍后 `θ_s(m) = arctan(m·tan20°)`。

误判滑动 = `θ_meas > θ_s(m)`：

```
F(m) = P(Z > (θ_s(m) − 20°)/σ) = ½ erfc( (θ_s−20)/(σ√2) )
```

偏差 `d(m) = θ_s(m) − 20°` 单调增，`F(m)` 单调减，故取最小满足 `F ≤ 0.5%`：

```
(θ_s − 20)/σ = z_{0.005} = 2.5758
θ_s = 20° + 1.2879° = 21.2879°    (m* = tan(21.2879°)/tan20° = 1.0705)
μ = m*·tan20° = 0.3896
```

“卡得稳”与“像粘住”的权衡全在这两条曲线：`m→1` 偏差 0 但误判率 50%；`m=1.2` 偏差 3.0° 但误判率 <1e-6。膝盖在 `m≈1.07`。

## 7. 验收门槛的口径

任务要求“临界角附近球在十秒内位移不得超过 R/100”。这对“必须静止”档是自然的：静止就该位移为零。但滚动与滑动档球本来就要下坡，位移必然远超 `R/100`。因此：

- 静止档：门加在**质心位移**上，`|s| ≤ R/100`；
- 滚动档：门加在**接触点滑移**上，`∫|u|dt ≤ R/100`（无滑滚动的本质就是滑移为零）；
- 滑动档：要求**接触点滑移超过** `R/100`（确实在滑）。

三档都照常打印实际位移与判定种类；任一超门会打印 `exceeded disp=… classification=…`。

## 8. 数值方法

半隐式欧拉，`dt = 1e-4 s`，`t = 10 s`。每步按接触点速度 `u` 判定模式并强制约束。滚动档把 `ω` 投影为 `−v/R` 使 `u` 精确为零。与解析解 `s = ½at²` 对比相对误差 1e-5（离散化误差），滚动档能量守恒到 `5e-3 J` 量级。
