# inclined — 球在斜面上的两个静摩擦临界角

`make test` 跑自检；`make report` 生成数据、图与蒙特卡洛校验。C11，无第三方依赖（绘图用 matplotlib）。

## 结论

| 情形 | 所需切向力 | 临界角 |
|---|---|---|
| 静止（质心不动） | `f = -m g sinθ` | `tanθ_s = μ` |
| 无滑滚动（接触点不动） | `f = -β/(1+β)·m g sinθ` | `tanθ_r = μ(1+β)/β` |

其中 `β = I/(mR²)`。两者相除：

```
tanθ_r / tanθ_s = (1+β)/β = 1 + mR²/I > 1     ⇒  θ_r > θ_s
```

差值只由转动惯量决定：实心球 β=2/5 → 3.5 倍，空心球 2/3 → 2.5 倍，圆环 1 → 2.0 倍。

**判别**（从静止释放）：`θ ≤ θ_s` 静止；`θ_s < θ ≤ θ_r` 无滑滚动；`θ > θ_r` 滑动。

## 为什么滚动档更“稳”

滚动时接触点瞬时不动，摩擦力不做功，只提供角加速度，所以它小于静止所需的整体平衡力。等价地看接触点滑移 `u = v + Rw` 的加速度：

```
du/dt = g cosθ · [ tanθ − μ(1+1/β)·sgn(u) ]
```

`u>0` 时 `tanθ < μ(1+1/β)` 才衰减，阈值正是 `tanθ_r`。代码里用这条独立路径交叉验证了滚动临界角。

## 陷阱：动摩擦公式给静止情形算不出切向力

速度求解器常用的摩擦是 `f_t = μ·|v_normal|`，在静止接触处 `v_normal = 0`，于是切向力为零，球缓慢下滑。**静摩擦必须按力平衡单独判定并夹在 `μN` 以内**。`inclined self` 里同一条 20° 坡跑两个求解器：

- 正确求解器：10 s 位移 `0`
- 纯动摩擦求解器：10 s 位移 `119.8 m`

另一个连带坑：滑移必须按**接触点**速度 `u = v + Rw` 判定，不能按质心速度——纯滚动的球质心速度非零但 `u = 0`，按质心判会误判成滑动。

## 系数取舍与标定

“拖到 20° 必须静止” ⇒ `μ₀ = tan20° = 0.364`。正好压在临界角上不稳，需放大 `m` 倍。两条曲线定系数（角度读数噪声 σ=0.5°）：

- 临界角偏差 `d(m) = θ_s(m) − 20°`
- 滑动误判率 `F(m) = P(θ_meas > θ_s(m))`

取最小满足 `F ≤ 0.5%` 的 `m`：`m* = 1.0705`，`μ = 0.3896`，`θ_s = 21.29°`，`θ_r = 53.75°`，偏差 1.29°，误判率 0.5%。两个临界角都满足要求（20° < θ_s < θ_r）。解析误判率经 20 万次蒙特卡洛验证，最大偏差 1.7e-3。

## 验收三档（每次 10 s）

`R = 1 m`，门 = `R/100 = 0.01 m`。位移门只约束“必须静止”档；滚动/滑动档把门加在**接触点滑移**上（那两档本来就该位移），同时照常报告实际位移与判定。

| 档 | θ | 期望 | 实测判定 | 位移 | 接触滑移 | 门 |
|---|---|---|---|---|---|---|
| A 低于静止临界 | 20.29° | 静止 | rest | 0.000 m | 0 | pass |
| B 两临界角之间 | 22.29° | 滚动 | rolling | 132.878 m | 0.000 m | pass |
| C 高于滚动临界 | 54.75° | 滑动 | sliding | 290.249 m | 14.476 m | pass |

另有距各边界 0.5° 的探针：`θ_r − 0.5°` 仍无滑（slip = 0），`θ_r + 0.5°` 立即滑动（slip = 7.24 m）。滚动档位移与解析 `½at²` 相对误差 1e-5，能量守恒。

## 局限

静/动摩擦按同一 `μ` 处理（未区分 `μ_s, μ_k`）；球视为刚体，未建模滚动阻力与接触变形，所以“静止”档位移严格为零而非极小蠕变。若加入滚动阻力系数 `C_rr`，静止档会在 `tanθ = C_rr` 处才开始蠕变，可在此基础上扩展。
