# degenerate

两球球心重合时的碰撞法线求解。`make test` 跑自检，`make` 同时产出
`libdegenerate.so` 供 `../experiments/` 经 ctypes 直接调用。

## 为什么会崩

球-球接触的教科书法线是

```
n = (cB - cA) / |cB - cA|
```

两球球心重合时分子分母同时为零，是 0/0 型：浮点结果为 NaN，沿法线的
冲量 `j ∝ vn = (vB−vA)·n` 随之全部变 NaN，求解器输出崩溃。自检里的
`naive_normal_is_nan` / `naive_impulse_is_nan` 复现了这一点。

## 极限为什么不能由位置确定

令 `d(t) = cB(t) − cA(t)`。重合瞬间 `d → 0`：

- 若相对速度 `d'` 有限且非零，洛必达法则给出
  `d/|d| → d'/|d'|`——极限存在，但等于**到达重合的运动方向**，
  依赖路径，不依赖当前位置，几何本身给不出这个方向；
- 若 `d' → 0`（静置重合、出生即重叠），位置与速度两个商同时消失，
  当前状态不含任何方向信息，只能向更早的帧或固定世界轴兜底。

## 四级兜底链（`sphere_contact`）

| 级别 | 条件 | 法线来源 | `NormalSource` |
|---|---|---|---|
| 1 | 球心距 > 尺度阈值 | 球心连线（B→A） | `NORMAL_FROM_POSITION` |
| 2 | 重合，当前相对速度非零 | 相对速度方向取反 | `NORMAL_FROM_VELOCITY` |
| 3 | 重合且速度近零，历史窗内有非零帧 | 回溯最近的非零位置/速度 | `NORMAL_FROM_HISTORY` |
| 4 | 整个历史窗都没有可用信息 | 固定世界轴（默认 +x） | `NORMAL_FROM_FIXED_AXIS` |

只要 `hit == 1`，返回的法线保证是有限单位向量，永不输出零向量或 NaN。
历史是每对球一个环形缓冲（`PairHistory`），深度 H 是唯一需要定标的参数，
定标方法与数据见 `../experiments/`。

## 固定轴为什么只滑不弹

固定轴与真实相对运动没有物理关系。当相对运动与该轴正交时，法向相对速度
为零，冲量为零、动能不损失（自检 `fixed_axis_no_energy_loss`）：两球不会
被弹开，只会在位置修正下沿轴滑开。对照用例 `velocity_path_bounces` 显示
速度分支能把同一运动变成真正的反弹（等质量、e=0.5 时两球分别取
+3.75 与 +1.25 的法向速度）。因此固定轴只允许作为最后兜底，其出现率必须
压在 1% 以下。
