# roll

滚动阻力：与角速度成正比的阻力矩，`make test` 跑自检。

## 模型与推导

滚动时接触点无相对滑动，阻力来自形变，不是滑动摩擦。设阻力矩

    τ = -c·ω

实心球 I = (2/5)mR²，由 I·dω/dt = -c·ω 及纯滚动 v = ωR 得

    v(t) = v0·e^(-λt),  λ = c/I

即**指数衰减而非线性**：速度永远到不了零，停止是渐近的。两个常用解析量：

- 停止时间（到阈值 v_th）：`T = ln(v0/v_th)/λ`
- 停止距离（到阈值 v_th）：`D = (v0 - v_th)/λ`，无阈值时渐近距离 `D∞ = v0/λ`

## 反解系数与阈值

两个设计目标反解两个未知量（λ 与 v_th）：

- 目标停止时间：参考速度 v_ref 的球在 t_target 后应"看起来停了"（降到 v_th）
- 可接受最大停止时间：任何不超过 v_max 的球滚动时间不得超过 t_max

联立 `ln(v_ref/v_th)/λ = t_target` 与 `v_th = v_max·e^(-λ·t_max)`：

    λ    = ln(v_max/v_ref) / (t_max - t_target)
    v_th = v_max·e^(-λ·t_max)
    c    = λ·I          （阻力矩系数）

当前取值 v_ref=2, t_target=2.5s, v_max=10, t_max=4s，得 λ≈1.073/s，v_th≈0.137 m/s。

## 取舍：停止距离 vs 滚动自然度

λ 的扫描（v0=10 m/s）：

| λ (1/s) | τ=1/λ (s) | D∞ (m) | 停止时间 (s) |
|---|---|---|---|
| 0.27 | 3.73 | 37.3 | 16 |
| 0.54 | 1.86 | 18.6 | 8 |
| **1.07** | **0.93** | **9.3** | **4** |
| 2.15 | 0.47 | 4.7 | 2 |
| 4.29 | 0.23 | 2.3 | 1 |

λ 偏小：τ 好几秒，球滚几十米才停，显得"冰面"。λ 偏大：不到半秒就停，
初速稍大也像撞墙，显得"黏"。1/λ 在 1 秒量级时两条曲线都可接受，与上面
反解出的值一致。

## 验证

三档初速（1.5 / 4.0 / 9.0 m/s）各跑一次，模拟用精确指数更新
（`v *= e^(-λdt)`，位移用解析积分），停止距离与解析值 `(v0-v_th)/λ`
的偏差要求 ≤10%，超了会打印实际距离。当前三档偏差均 <0.1%。

## 边界：低速阈值强制归零

指数衰减的尾部无限长：从 9 m/s 衰减到 1 mm/s 需要约 8.5 s，远超
t_max=4 s，球会长时间"蠕行"。因此 |v| ≤ v_th 时直接把 v（及 ω）置零，
阈值本身由可接受最大停止时间反解（见上），保证任何 v0 ≤ v_max 的球
停止时间都不超过 t_max。
