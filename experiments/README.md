# experiments

退化法线的历史帧数定标实验。所有法线都由 `../degenerate/libdegenerate.so`
经 ctypes 实时计算，Python 只负责造场景与记账，不存在第二份算法实现。

## 运行

```
make -C ../degenerate          # 先建 libdegenerate.so 并跑 23 项自检
python3 -I run_experiment.py   # 三档重叠 × 11 个 H，约 25 秒
python3 -I make_report.py      # 读 JSON 生成 ../artifacts/report.html
python3 -I check_svg.py        # 报告里 SVG 的静态几何校验
```

## 为什么需要显式事件模型

自由动力学下球心**精确**重合是零测度事件，仿真里实际碰不到；真实引擎中的
重合来自出生重叠、位置修正塌陷和静置滞留。因此实验在普通动力学之外注入
受控的重合事件流，且事件走独立的受控解析通道（`_resolve_event`），
指标不受环境碰撞干扰：

- `head_on`：球心重合、相对速度非零 → 速度分支，与历史深度 H 无关；
- `stasis`：球心重合、两球静止，先向环形缓冲写入 K 个零帧（K ~ 几何分布，
  q=0.10，均值 10 帧）→ 恢复需要窗口深于 K，否则落到固定轴。

环境动力学仍然全程运行，138000 次接触评估只做一件事：验证任何环境接触都
不会产生非法线（实际失效 0 次）。

## 帧数反解

静置 K 服从几何分布，窗口深 H 时取不到证据的概率是几何尾部

```
P(K ≥ H) = (1 − q)^H
```

要求固定轴兜底率 ≤ 1%：

```
H ≥ ln(0.01) / ln(1 − q) = ln(0.01) / ln(0.9) ≈ 43.7 → 44 帧
```

经验穿越点受有限样本噪声影响（每档仅约 200 个静置事件，H=48 处尾部
期望只剩约 1 个事件）：中、深档在网格点 H=48 穿越 1%，浅档因尾部最粗
在 H=64 才穿越。取三档最保守者，定标 **H=64**。内存随 H 线性增长：
每帧每对 24 字节（两个 V3），24 球共 276 对，H=64 时约 414 KiB；
外推 1000 球（499500 对）约 732 MiB（0.72 GiB），大规模场景需要配合
宽相/休眠对压缩历史内存。

## 输出（`../artifacts/data/`）

| 文件 | 内容 |
|---|---|
| `runs.json` | 三档 × 11 个 H 的恢复率、两类固定轴率、来源计数、内存 |
| `age_cdf.json` | K 的经验直方图、按 H 的恢复曲线、K↔回溯年龄(K+1) 核对 |
| `frame0_audit.json` | 每档三个预埋重合对的法线审计（含球编号与法线值） |
| `failures.json` | 非法线/零向量事件清单（本次为空） |
| `memory.json` | 内存曲线与几何尾部解析反解 |

## 固定轴 1% 验收

`fixed_in_stasis` 是真正受 H 约束的指标（head_on 事件永远走速度分支，
计入 `fixed_conditional` 但不随 H 变化）。H=48 时三档静置固定轴率为
1.90% / 0.47% / 0.51%（浅档未达标）；H=64 时三档均为 0.00%，全事件
固定轴率也为 0.00%，满足低于 1% 的验收线。
