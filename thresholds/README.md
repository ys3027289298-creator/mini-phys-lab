# thresholds

休眠 / 退化 / 穿透三个判定阈值的**可观测物理推导、误判率反解与调参方案对比**。
不引入新的拍脑袋常数：每个阈值都从可观测量推出物理尺度，再由目标误判率
经单调关系反解取值。

| 文件 | 职责 |
|---|---|
| `src/derive.py` | 三个阈值的闭式推导、窗口反解、可行性判定（纯标准库，`python -I` 可跑） |
| `src/engine.py` | `collide/solve/integrate` 三个 C 模块的 2D 移植 + 三套判定 + 带噪观测 + 真值标签 |
| `src/experiments.py` | 五场景套件、校准层、独立/联合/经验三种调参、一成偏差校验 |
| `src/plots.py` | 四条决策曲线（依赖 matplotlib，仅绘图用） |
| `results/` | `report.json`、`calibration.csv`、四张 PNG |

```bash
python3 -I src/derive.py        # 推导与窗口速览
python3 -I src/experiments.py   # 全量实验，约 2 分钟
python3 -I src/plots.py         # 读图重画
```

## 1. 三个阈值从可观测物理量推导

记号与标定值（SI，见 `derive.Observables`）：

| 量 | 含义 | 取值 |
|---|---|---|
| `r` | 球半径 | 0.5 m |
| `mu_s` | 最大静摩擦系数 | 0.4 |
| `g, dt` | 重力、帧步长 | 9.8 m/s²，1/60 s |
| `sigma_v / sigma_d / sigma_p` | 速率/重叠/穿透观测 1σ 噪声 | 0.01 / 2e-5 / 3e-3 |
| `eps_r` | 最小可分辨重叠的相对量级 | 2e-4 |
| `h, v_max` | 地板厚度、单球最大速率 | 0.1 m，4 m/s |
| `delta0` | 静息位置修正 slop | 1e-3 m |
| `k` | 连续低速休眠帧数 | 4 |

### 1.1 休眠阈值 `v_sleep` —— 最大静摩擦能维持的坡度

最大静摩擦兜得住的临界坡角满足 `tan(theta_max) = mu_s`。临界坡面上重力
切向加速度与一帧内获得的最小物理速率：

```
sin(theta_max) = mu_s / sqrt(1 + mu_s^2)
v_min = g·dt·sin(theta_max) = g·dt·mu_s / sqrt(1 + mu_s^2)        # = 0.0607 m/s
```

真在动的球，速率不可能长期低于 `v_min`；低于它的"运动"只可能是观测噪声。

### 1.2 退化阈值 `d_deg` —— 半径与最小可分辨重叠

接触深度低于 float32 深度运算与几何公差的分辨率时，切向流形不可信，应退化为
法向单冲量。最小可分辨重叠正比于半径：

```
delta_res = eps_r · r                                                # = 1.0e-4 m
```

### 1.3 穿透阈值 `p_tun` —— 地板厚度与单帧最大位移

一帧最大位移 `delta_max = v_max·dt`。要保证本帧不整块穿过厚 `h` 的薄板，
触发连续碰撞检测（CCD）的深度预算必须留下完整位移余量：

```
p_head = h - v_max·dt                                                # = 0.0333 m
```

## 2. 用目标误判率反解阈值（单调关系）

三类判定共用同一统计模型：观测量 `X ~ N(s, sigma^2)`，`s` 是上节的物理尺度。
误判率随阈值单调，用 `z = Phi^-1(alpha)` 反解。每个阈值都有**两侧**误判，
因而得到一个可行窗口而非单点。

| 阈值 | 漏判侧（阈值过松） | 误报侧（阈值过紧） |
|---|---|---|
| `v_sleep` | 误睡 `Phi((T-v_min)/sigma_v) ≤ alpha` → 上限 `v_min + sigma_v·z(alpha)` | 连续 k 帧误醒 → 下限 `sigma_v·z((1-alpha)^(1/k))` |
| `d_deg` | 漏退化 `Phi((T-delta_res)/sigma_d) ≤ alpha` → 上限 | 零重叠误留 → 下限 `sigma_d·z(1-alpha)` |
| `p_tun` | 漏 CCD `Phi((T-p_head)/sigma_p) ≤ alpha` → 上限 | slop 误报，静息 `~N(delta0,sigma_p^2)` → 下限 `delta0 + sigma_p·z(1-alpha)` |

窗口内统一取 **75% 分位**（在压住漏判上限的前提下尽量压低误报）。
给定可接受误判率 `alpha`，阈值上限被唯一钉死——这正是"误判率与阈值单调，
给定预算就能定阈值"的含义。

**可行性边界（真实算出来的，不是假设）**：`alpha=0.005` 时退化窗口倒置
（`delta_res` 只有 5σ_d 的分离度，双侧 0.5% 预算装不下），故主实验取
`alpha ∈ {0.05, 0.02, 0.01}`。

## 3. 三者的耦合

引擎里显式记录三条耦合链（`engine.Counters`）：

- **C1 推穿**：休眠球被高速球撞击，唤醒有延迟时不积分，位置修正把它推进
  薄板深处（`depth > p_head`）。对应题目"穿透阈值过松会让休眠球被推穿"。
- **C2 抖动误报**：本该睡着却醒着的慢速球，在 slop 上方抖动，把普通接触
  误判成穿透风险、触发昂贵 CCD。
- **C3 永不休眠**：休眠阈值过低（`v_sleep` 太小），临界坡面上的慢速球
  一直满足不了休眠条件，整段保持唤醒。对应"休眠阈值过低会让慢速球一直醒着"。

耦合还进入穿透窗口本身：唤醒延迟 `L` 帧必须额外预留位移裕
`margin = v_max·dt·L`，穿透几何上限收窄为 `p_head - margin`。
**压力试验（L=1）下 margin=0.0667 m > p_head=0.0333 m，窗口倒置——几何上
不存在能同时压住漏判与误报的正阈值**，报告中标记 `feasible=false` 并回退到
无耦合基准窗口，同时给出原因。这种情况靠调 `p_tun` 无解，必须缩短唤醒延迟
或限制 `v_max`。

### 取舍：独立调 vs 联合调

| | 独立调参 | 联合调参 |
|---|---|---|
| 做法 | 三个阈值各用闭式反解，互不含耦合项 | 坐标下降解三变量约束，双层接受准则（先压违规数再压冲突数） |
| 调参耗时 | ~0 s，1 次套件评估 | ~20 s，55–60 次套件评估 |
| 冲突数（α=0.05） | 172 | 120（−30%） |
| 阈值偏差 | 全部 ≤10% | 为消冲突主动移出窗口，sleep 最大偏离 42% |
| 适用 | 物理尺度清晰、耦合事件可接受 | 预算紧、耦合冲突占成本大头 |

决策依据就是题目要求的两条曲线：`fig1_conflict_curve.png`（冲突次数 vs 预算）
与 `fig2_tuning_cost.png`（耗时/评估数 vs 方案）。在本标定下，α≥0.02 时
独立调参已零违规，建议默认独立调参；只有当 C1/C2 事件的下游代价超过约 20 s
调参成本时才上联合调参。

## 4. 三种参数组合与一成偏差校验

每个 `alpha` 跑三种取法，九项校验（3 方法 × 3 阈值），偏差超过 10% 必须指出
是哪个阈值、为什么。结果（主实验，当帧唤醒；独立与经验两种方法在三个 α 下
**全部 9 项通过**，下表只列联合调参的超差项）：

| α | 独立/经验 | 联合调参冲突变化 | 联合调参超差阈值与偏差 | 违规数 |
|---|---|---|---|---|
| 0.05 | 全过（≤0.5%） | 172 → 120（−30%） | sleep −42.3%，degrade +14.6%，pen +24.7% | 0 |
| 0.02 | 全过（≤0.3%） | 139 → 127（−9%） | sleep −29.5%，pen +22.6% | 0 |
| 0.01 | 全过（≤0.5%） | 140 → 128（−9%） | pen +21.1% | 1（两种方法都剩 1 项预算违规） |

关键结论：

1. **独立调参与经验校准在所有 α 下都满足一成**（多数 <1%，与 10 万探针的
   蒙特卡洛标准误 ~0.45% 一致），证明闭式推导与仿真同口径。
2. **联合调参的超差不是公式错误，而是显式的约束权衡**：报告每项超差都带
   `reason` 字段，说明是哪个阈值、为压住多少耦合冲突而移出窗口。分项计数
   （`fig4`）显示 α=0.05 时三类冲突同时下降（C1 136→103、C2 31→14、
   C3 5→3）；α 收紧后可压的主要是 C2 抖动，C1 受几何预算限制基本不动。
3. **压力试验 L=1**：穿透窗口几何不可行，`p_tun` 的一成校验对"回退后的基准
   窗口值"进行（该组 9 项中仅联合调参的 sleep 超差）；这是题目要求的
   "任一超出要给出阈值与原因"的结构性案例——几何上无解，只能缩短唤醒延迟
   或限制 `v_max`，不能靠继续调 `p_tun`。

### 仿真与 C 模块的一致性

`engine.py` 的三个接触/求解/积分函数逐式对应 `collide.c`、`solve.c`、
`integrate.c`（最近点法线、摩擦不反向、半隐式欧拉 + 位置修正撞地清零），
所有误判统计都用无噪真值打标签，噪声只加在观测上，避免把仿真误差误记成
判定误差。
