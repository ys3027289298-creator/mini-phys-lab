# chain

一排球的一维弹性传递链：第一颗以速度 u0 撞向静止球列，相邻球对只碰一次，
冲量沿链前进。`make test` 跑自检并打印权衡与三档结果。

## 推导

第 k 颗（质量 m1、速度 u）撞静止的第 k+1 颗（质量 m2），弹性：

```
m1 u = m1 v1 + m2 v2
½m1 u² = ½m1 v1² + ½m2 v2²      =>  v2 = 2m1 u/(m1+m2)
E_{k+1}/E_k = m2 v2²/(m1 u²) = 4 m1 m2/(m1+m2)²
```

所以第 n 颗收到的能量

```
E_n/E_1 = Π_{k=1..n-1} 4 m_k m_{k+1}/(m_k+m_{k+1})²
```

等质量时每项为 1，能量几乎全部到最后一颗。等比递增 m_{k+1}=ρ m_k 时

```
T(ρ) = 4ρ/(1+ρ)²          单链效率
E_n/E_1 = T^(n-1)
L(ρ) = ln0.1/lnT(ρ)       能量降到一成的链长（步数）
```

反解长度：

```
T = 0.1^(1/L),   ρ(L) = (2 - T + 2√(1-T)) / T        （取 ρ≥1 支）
```

前两颗的弹飞速度（单位 u0）：

```
|v1| = (ρ-1)/(ρ+1),   |v2| = 2(ρ-1)/(ρ+1)² = 2|v1|/(1+ρ)
```

## 权衡

`ρ` 越大 `L` 越短，但 `|v1|` 越接近 u0、`|v2|` 越大。让前两颗都“被弹飞”
（各 > 0.85 u0）需要 ρ 很大；反过来 ρ→1 时整排都在动。给定“第四颗 < 2%”
的门槛：

```
E4/E1 = T³ < 0.02  =>  T < 0.02^(1/3) = 0.27144  =>  ρ > 12.657,
L(12.657) = 1.766 步
```

`make test` 打印 `ρ, T, L, |v1|, |v2|` 两条曲线。

## 反解质量分布

不用试：给定目标 `E_n/E_1`，逐链反解 ρ = ratio_for_frac(T_per_link)。

目标：第二颗拿 50%，第三颗 10%，第四颗 1.9%（<2%）

| k | 目标累计 | 单链 T | ρ | 质量 |
|---|---|---|---|---|
| 1→2 | 0.50 | 0.50 | 5.8284 | 5.8284 |
| 2→3 | 0.10 | 0.20 | 17.9443 | 104.5869 |
| 3→4 | 0.019 | 0.19 | 19.0000 | 1987.1507 |

模拟碰后速度 `v = [-0.7071, -0.2620, -0.0278, 0.0031]`（u0=1），
第四颗几乎不动；动量、能量均守恒。
