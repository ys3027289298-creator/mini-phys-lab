# 复盘：运动学物体被当作动态物体求解

> 基线 `2c0cca1`。可视化版本：`docs/retro-kinematic-mislabel.html`。
> 本文的数字全部由仓库内可复现命令测得；复现方式见文末。

## 一句话

事故不是「漏了一个判断」，而是「接口里没有类型这个概念」。因为概念缺失，100% 的行覆盖和调用覆盖都兜不住它；所以修法不是加测试或加分支，而是把物体类型变成接口的**必填参数**，让错误在编译期暴露。

## 为什么当时没发现（数据）

| 量 | 实测 | 说明 |
|---|---|---|
| 「类型标错」调用点 | **0 / 11**（0%） | 类型概念不存在，无所谓「标错」 |
| 运动边界总调用点 | 11 | 6 处 `resolve` + 5 处 `step` |
| 断言总数 | 28 | solve 10 + integrate 6 + collide 12 |
| 提及 body kind 的断言 | **0 / 28** | 没有任何一条验证运动学语义 |
| 事故前行覆盖 / 调用覆盖 | **100% / 100%** | 三模块全绿 |
| 分支至少执行一次 | 56.8%–77.3% | 逐模块；事故前无类型相关分支可覆盖 |

**反解。** 设已有 k 个调用点声明了类型，要必然兜住至少一次标错，所需覆盖率为 `f = 1 − k/N`（N=11）；
80% 把握则为 `f = 1 − 0.2^(1/(N−k))`。现实 k=0，解得 **f = 100%**——而这正是事故前的实测值。
目标已达成、事故仍发生，说明**覆盖率不是这类缺陷的护栏**：缺陷不在某条没跑到的分支里，而在接口层。

## 设计约束（让错误不可能发生）

把 `BodyType` 变成 `step` / `resolve` 的**第一个必填参数**，且：

1. **无默认值**——调用点无法省略；
2. **结构体包装而非裸 enum**——`0`/`1` 字面量不能隐式转换（裸枚举在 gcc/clang 最大告警下会静默接受字面量）；
3. **策略 `switch` 穷举 + `-Wswitch-enum`**——新增 kind 而不给策略直接编译报错。

运动学语义：`integrate` 不积分重力、不做位置修正；`solve` 质量无穷大、速度不被冲量改写。
这就是事故根因（位置修正「推」了本该沿既定路径走的物体）被消除的地方。

## 取舍（改动行数 vs 复发风险）

同一改造范围、两模块、只算签名+策略+调用点：

| 方案 | 改动行 | 可静默编译通过的错误形态 | 判定 |
|---|---:|---:|---|
| 默认值字段 | 7 | 3（随每个新物体增长；**实测仍复现事故**） | 否 |
| 裸枚举必填 | 30 | 22（11 点 × 字面量 0/1） | 中间态 |
| **结构体必填** | **36** | **0** | **采纳** |

默认值方案实测：物体从 `y=0.25` 被推到 `0.500`、`vy` 清零，与事故一模一样，且 `-Werror` 下零告警——
「方便但会再犯」被坐实。多花 29 行买「处处可犯 → 0」，最后一手 6 行把字面量也堵死。

## 验证（编译必须失败得恰到好处）

`make -C solve contract` 对 8 个形态逐一单独编译，判定只看编译器是否报错；应被拒绝却编译通过则该测试自身失败。

| 形态 | 期望 | 实测 cc / clang |
|---|---|---|
| 漏类型（`step` / `resolve`） | 报错 | 拒绝 |
| 字面量 `0` / `1` | 报错 | 拒绝 |
| 正确具名常量（两种 kind） | 零告警 | 通过 |
| 同一 TU 同时 include 两个模块头 | 零告警 | 通过 |

行为回归：`integrate` 的 `kinematic_not_corrected`、`kinematic_path_unchanged`；`solve` 的
`kinematic_untouched`、`kinematic_velocity_unchanged`、`kinematic_no_impulse_loss`。
全仓库在 `-Wall -Wextra -Werror -Wswitch-enum -pedantic` 下三模块 `all_ok=1`。

## 已知盲区

- 编译器拦「没标」，**拦不住「标反」**（显式写 `BODY_DYNAMIC` 而心里想运动学）。这类只能靠行为断言兜底。
- 类型块在 `solve.h` / `integrate.h` 各有一份（同 `BODY_TYPE_H` 守卫保证不冲突），需字面一致；
  长期正解是抽共享 `phys_types.h`，但会耦合两个独立可构建的模块，留作后续决策。

## 复现

```sh
for d in collide solve integrate; do
  make -C $d clean && \
  make -C $d CFLAGS="-O2 -std=c11 -Wall -Wextra -Werror -Wswitch-enum -pedantic" test
done
make -C solve contract            # 编译契约；CC=clang make -C solve contract 亦然
```
