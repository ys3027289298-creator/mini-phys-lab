# broadphase

球-球碰撞的均匀网格宽相（spatial hash 形式的包围盒剔除）+ 精确距离窄相，
用于回答“盒尺寸 h 怎么取”。`make test` 跑自检，`make sweep` 扫描 h 输出 CSV。

## 两阶段判据

- 宽相：球心所在单元 + 3×3 邻域内的球组成**候选对**（等价于包围盒/AABB 相交测试）。
- 窄相：每个候选对仍要跑精确距离判据 `d² ≤ (r_i+r_j)²`。盒相交只是必要条件——
  对角相邻时两个盒只在角点接触，球心距离可以远大于半径和，这类候选是假阳性
  （`false_pos` 列），必须由窄相拒绝。

## 留存比例（盒剔除后仍需窄相的比例）

球在 L×L 平面均匀分布，每单元平均 λ = N(h/L)² 个球。网格数 g=L/h ≫ 1 时：

```
C_bp    ≈ (9/2)·N²·(h/L)²
f_narrow = C_bp / C_all ≈ 9·(h/L)²          C_all = N(N−1)/2
```

f_narrow 只依赖 **h/L，与 r 无关**：假阳性尺度完全由盒尺寸决定。g ≤ 3 的粗网格
下边界单元邻域不足 9 格（角格只扫 4 格），实测低于该式，报告图 B 可见分离。

## 反解盒尺寸

给定窄相预算 f*（占全量两两检测的比例上限）：

```
h ≤ (L/3)·√f*        例：f*=1% → h ≤ 0.0333L；f*=50% → h ≤ 0.236L
```

## 零漏检约束

碰撞球心间距 ≤ r_i+r_j，要保证两球单元索引之差不超过 1，必须 h ≥ r_i+r_j；
等半径即 **h ≥ 2r**。与预算约束联立得可行窗口：

```
2·r_max ≤ h ≤ (L/3)·√f*
```

窗口为空说明单一均匀网格无法同时满足零漏检与预算，需要分层网格或扫掠-排序。
窗口下沿 h=2r 即最紧零漏检盒，窄相调用最少。

## 退化判据（r ≪ h，宽相失效）

f_narrow ≈ 9(h/L)² 与 r 无关，所以失效只由 h/L 决定：

```
失效（f_narrow ≥ f*）  ⟺  h/L ≥ √(f*/9)
完全失效（f_narrow→1） ⟺  h/L ≳ 1/3，即 g = L/h ≲ 3
占用率形式             ⟺  λ = N(h/L)² ≥ Nf*/9
```

实测 h=45.3（g=2）时所有单元互为邻域，f_narrow=1.00：宽相完全退化为全量两两检测。

## 实验设置与结果（N=400, L=100, 三档等半径）

全量基线 C_all = 79,800 次/帧。每档固定随机种子，h 按 √2 步进扫描 19 个点。

| r | 最紧零漏检 h=2r | 窄相调用 | 相对全量下降 | 漏检 | 真碰撞对数 |
|---|---|---|---|---|---|
| 0.5 | 1.0 |    59 | 99.93% | 0 |  21 |
| 1.0 | 2.0 |   303 | 99.62% | 0 | 123 |
| 2.0 | 4.0 | 1,182 | 98.52% | 0 | 392 |

h < 2r 时三档全部出现漏检（如 r=2、h=2 时漏 108 对），与零漏检约束一致。

## 文件

- `src/broadphase.c` — 网格宽相、暴力参考实现、自检与扫描（`test` / `sweep`）
- `results.csv` — 三档 × 19 个 h 的完整数据
- `tools/make_report.py` — 纯标准库，CSV → 单文件交互 HTML（十字线 + 悬浮提示、
  浅/深色、可滚动数据表）：`python3 -I tools/make_report.py results.csv report.html`
- `report.html` — 生成好的报告，浏览器直接打开
