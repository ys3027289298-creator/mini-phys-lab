宽相包围盒剔除：盒尺寸 h 的取舍

场景 N=400 个球，L=100×100 平面均匀分布；三档等半径 r ∈ {0.5, 1.0, 2.0}，每档固定随机种子。全量两两检测 = N(N−1)/2 = 79,800 次。

1. 为什么盒相交后仍必须跑窄相

两个球的包围盒（以球心为中心、边长 2r 的正方形；网格实现里等价为“所在单元 + 3×3 邻域”）相交只说明球心坐标差在各轴上都不超过阈值，并不约束欧氏距离。对角相邻时，盒在角点接触而球心相距 √2·h 量级，可远大于 ri+rj。因此宽相输出的是候选对，每个候选对仍需一次精确距离判据：

窄相命中 ⟺ dij2 = (xi−xj)2 + (yi−yj)2 ≤ (ri+rj)2

实验里 false_pos 一列就是“盒留存但窄相拒绝”的假阳性：在 r=0.5、h=8 时 4,339 个候选里 4,318 个是假阳性，仅 21 个真碰撞。

2. 盒剔除后仍需窄相检测的比例（由 r/h 与 h/L 决定）

均匀分布、每单元平均 λ = N(h/L)2 个球。每个球扫描 3×3 共 9 个单元，候选对数量与窄相留存比例（网格数 g=L/h ≫ 1 时）：

Cbp ≈ 9N·λ/2 = (9/2)·N2·(h/L)2 fnarrow = Cbp / Call ≈ 9·(h/L)2，其中 Call = N(N−1)/2

fnarrow 只依赖 h/L，与球半径 r 无关：假阳性的尺度完全由盒尺寸决定。r 只通过零漏检约束 h ≥ 2r 出现在另一侧（见第 4 节）。g ≤ 3 的粗网格下边界单元邻域不足 9 格，实测值低于该式（角格只扫 4 格），图 B 中可以看到实测曲线与理论虚线在细网格段重合、粗网格段分离。

3. 用比例反解盒尺寸

给定可接受的窄相预算 f*（占全量两两检测的比例上限），由上式反解：

h ≤ L·√(f*/9) = (L/3)·√f* 例：f* = 1% → h ≤ 0.0333L；f* = 50% → h ≤ 0.236L

4. 零漏检约束与最终取值区间

碰撞球心间距 ≤ ri+rj。要保证两球所在单元索引之差不超过 1，必须 h ≥ ri+rj；等半径下即 h ≥ 2r。与预算约束联立，盒尺寸的可行窗口为：

2·rmax ≤ h ≤ (L/3)·√f*

窗口为空（2rmax > L√f*/3）说明单一均匀网格无法同时满足零漏检与预算，需要分层网格或扫掠-排序等方案。取窗口下沿 h=2r 即“最紧零漏检盒”，窄相调用最少。

6. 退化情形：r ≪ h 时宽相失效的判据

球半径远小于盒尺寸时，单元内球数 λ = N(h/L)² 很大，3×3 邻域几乎覆盖全场景，宽相退化为全量两两检测。由于 fnarrow ≈ 9(h/L)² 与 r 无关，失效判据也只由 h/L 决定：

失效（fnarrow ≥ f*）⟺ h/L ≥ √(f*/9) 完全失效（fnarrow → 1）⟺ h/L ≳ 1/3，等价于 g = L/h ≲ 3 占用率形式：λ = N(h/L)² ≥ Nf*/9（本场景 N=400、f*=0.5 → λ ≳ 22 球/单元）

实测：h=32（g=3）时 fnarrow=0.59，h=45.3（g=2）时所有单元互为邻域，fnarrow=1.00——宽相完全不起作用，与判据一致。此时真碰撞仅数十对，假阳性占候选的 99.5% 以上。
