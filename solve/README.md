## 摩擦锥模型（库仑摩擦，单位质量）

墙的外法向为单位向量 $\mathbf n$，入射法向分量 $v_n=\mathbf v\!\cdot\mathbf n<0$，
切向速度分解到两个正交切向轴 $\mathbf t_1,\mathbf t_2$ 上。

### 1. 约束不等式

法向冲量 $j_n=(1+e)|v_n|$（$e$ 为恢复系数）。摩擦锥限定切向冲量上限：

$$|\mathbf j_t|\le \mu\,j_n=\mu(1+e)|v_n|,\qquad \tan\alpha=\mu$$

$\alpha$ 为锥的半角，张开角 $=2\alpha$。实现中对两个切向轴分别裁剪
（摩擦锥的棱锥形式），每轴最多削掉 $\delta=\mu(1+e)|v_n|$，且不允许反向。

### 2. 切向速度的最大削减比例

$$r_i=\frac{|v_{t,i}|-|v'_{t,i}|}{|v_{t,i}|}
=\min\!\left(1,\ \frac{\mu(1+e)|v_n|}{|v_{t,i}|}\right)$$

两个切向轴被削掉的**绝对量相同、比例不同**：分量小的轴先到 $r=1$
的黏滞平台（贴住不动），分量大的轴继续滑——方向性由此产生。
早期实现对整个切向向量乘同一标量，各向衰减比例恒等，不符合摩擦锥。

### 3. 由目标比例反解锥角

给定入射角下希望切向轴 $i$ 的衰减比为 $r^*$：

$$\mu=\frac{r^*|v_{t,i}|}{(1+e)|v_n|},\qquad
\alpha=\arctan\mu$$

代码中 `design_friction()` 完成该反解，`cone_angles()` /
`material_from_cone()` 在 $\mu$ 与锥角间互转。

取舍（见 `artifacts/friction_cone_ratios.png` 左图）：锥角增大时
$r_1(\alpha)$、$r_2(\alpha)$ 两条曲线先后贴上 $r=1$——角太大各向都被
刹死、失去方向性；角太小只有小分量方向被削。本实验室取工作点
$e=0.3,\ \mu=0.4$，即半锥角 $\alpha=21.80°$、张开角 $43.60°$。

### 4. 90° 锥角是不可行边界

$\alpha=90°\Rightarrow\mu=\tan90°=\infty$，切向冲量不再受法向冲量约束，
任意滑动都被完全吃掉；若 $e=0$，法向分量同时归零，球撞墙后
$\mathbf v'=0$ 直接贴住。合法域为 $\alpha\in[0,90°)$，
`material_from_cone(90°, ...)` 返回 `-3` 判越界。

## 自检结果（`make test`）

三档入射角 15°/30°/45°，切向速度按 35° 拆到两个正交轴，实测衰减比与
理论值 $r_i$ 的偏差均为 0（预算 3%，超差时打印实际比）：

| 入射角 | r1 实测/理论 | r2 实测/理论 |
|---|---|---|
| 15° | 0.1701 / 0.1701 | 0.2429 / 0.2429 |
| 30° | 0.3665 / 0.3665 | 0.5234 / 0.5234 |
| 45° | 0.6348 / 0.6348 | 0.9066 / 0.9066 |

另测 55° 斜入射：小分量轴 $r_2=1.0000$ 已贴住、大分量轴 $r_1=0.9066$
仍在滑，验证方向性；以及 90° 越界拒绝、极限参数下残余速度为 0。
