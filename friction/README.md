# friction

两球斜撞的法向 + 切向（库仑）冲量求解，附摩擦上限扫描实验。`make test` 跑自检。

## 1. 伪代码审查：缺了什么

原伪代码只在法向施冲量，**完全没有切向摩擦项**。斜撞时相对速度可分解为

- 法向分量 v_n = (v_b−v_a)·n —— 被冲量处理；
- 切向分量 v_t = (v_b−v_a) − v_n n —— 冲量前后不变。

接触在一帧内不会自然结束：球沿切向继续滑移，下一帧仍处于重叠状态，于是反复触发碰撞分支。实验（`baseline.csv`）表明五组斜撞全部穿透，最大穿透 1.21–1.68 个半径；仅补"接近速度守卫"（v_n≥0 不施冲量）数据完全不变，证明守卫不是修法，缺的就是切向冲量。

实验还暴露了另外两个缺陷：

1. **每帧重算完整法向冲量**。持续接触中接触法线随滑移旋转，残留切向速度被旋转后的法线读成新的接近速度，冲量逐帧放大（相对速度可从 10 涨到 90），穿透滚雪球。修法：冲量只在接触事件首帧施加一次（瞬时冲量模型），后续重叠帧只做位置投影。
2. **离散检测使法线失真**。发现重叠时球已深入，接触点法线偏离真实值，斜角越大冲量误差越大（75° 时达 37%）。修法：CCD 回退，解 |d(t)|=2r 的二次方程，在精确接触瞬间施冲量再走完剩余子步。修正后与解析解误差 <0.001%。

## 2. 补上摩擦后的冲量表达式

记 K = inv_m_a + inv_m_b，t 为沿切向相对速度方向的单位切向，冲量使 a 受 +J、b 受 −J：

```
法向：  Jn = −(1+e)·v_n / K          （仅 v_n < 0 时）
切向：  Jt = min( |v_t|/K , μ·Jn )    方向与切向相对速度相反
总冲量：J = Jn·n + Jt·t
 a: v_a += J · inv_m_a
 b: v_b −= J · inv_m_b
```

`|v_t|/K` 是把切向相对速度恰好清零所需的冲量（黏着冲量）；`μ·Jn` 是库仑锥上限。两者取小，摩擦永远不会把切向速度反号。

## 3. 反解摩擦冲量的上限

若写成固定比例 |Jt| ≤ k·Jn 并盲目施加 Jt = k·Jn，反号条件为

```
v_t' = v_t − K·Jt < 0  ⇔  k > v_t / (K·Jn)
```

代入本实验等质量（K=2）、入射速率 v、入射角 θ：v_n = −v·cosθ，v_t = v·sinθ，

```
Jn = (1+e)·v·cosθ / K
临界上限  k* = v_t / (K·Jn) = tanθ / (1+e)
```

| θ | 15° | 30° | 45° | 60° | 75° |
|---|---|---|---|---|---|
| k* = tanθ/(1+e) | 0.179 | 0.385 | 0.667 | 1.155 | 2.488 |

- k 给得紧（k≪k*）：摩擦远不足，球贴着接触面长距离滑移；
- k 给得松（k>k*）：切向速度被反号，接触几何紊乱，滑移距离重新拉大。

## 4. 用两条曲线定上限（`cap_sweep.png`）

对 k∈[0,4] 扫描，每个 k 跑五组斜撞：

- 上图 **反号次数曲线**：每条曲线在各自 k* 处从 0 阶跃到 1，阶跃位置与解析虚线精确重合，网格上最后一个零反号点（0.1/0.3/0.6/1.1/2.4）从下方夹住理论值；
- 下图 **滑移距离曲线**：k 过小时滑移大，越过 k* 后因反号导致接触路径改变而再度抬头。

两曲线的共同可行域是"反号为零且滑移尽量小"。固定 k 无法同时满足五组角度（k* 从 0.18 到 2.49 跨一个数量级），因此选取**自适应库仑上限 k=μ=0.5，配合黏着冲量取小**：每组角度自动落在 min(k*, 0.5)，反号恒为零。

## 5. 五组斜撞各跑一次的结果（`impulse_ratio.png`，μ=0.5）

|---|---|---|---|---|---|---|
| 15° | 7.244 | 1.294 | **0.179** | 滑动（μJn 受限） | 0 | 3.143 |
| 30° | 6.495 | 2.500 | **0.385** | 滑动（μJn 受限） | 0 | 3.231 |
| 45° | 5.303 | 2.652 | **0.500** | 黏着（切向清零） | 0 | 3.154 |
| 60° | 3.750 | 1.875 | **0.500** | 黏着（切向清零） | 0 | 2.487 |
| 75° | 1.941 | 0.971 | **0.500** | 黏着（切向清零） | 0 | 1.537 |

冲量分配比即 Jt/Jn：小角度由库仑锥限制（0.179、0.385），45° 起由黏着冲量限制并钉在 0.500。五组反号次数均为 0，无隧穿（球心距始终 ≥ 1.5r，最大穿透为单帧位移级且首帧即被投影修正）。表中 Jn、Jt 与解析解 Jn=(1+e)v·cosθ/K、Jt=min(v·sinθ/K, μJn) 误差 <0.001%。

## 命令

```
make test                 # 自检（含临界反号、legacy 失效路径、穿透边界）
./friction baseline       # 原伪代码 vs 仅加接近守卫 → artifacts/.../baseline.csv
./friction sweep          # k 扫描 + 库仑工作点 CSV
./friction final          # 五组斜撞在选定上限下各跑一次
./friction trace <场景0-4> <模式0/1> <k> <守卫> <位置修正> <legacy>
```

实验参数：等质量单位球（r=1，inv_m=1），入射速率 10，恢复系数 e=0.5，μ=0.5，dt=0.02。
